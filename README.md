**`Penetration Testing Analyst`**

Me chamo Hercolys Silva, sou apaixonado por hacking e segurança ofensiva. Sou fascinado por entender como sistemas funcionam, explorar suas estruturas, descobrir vulnerabilidades e enxergar possibilidades que muitas vezes passam despercebidas.

Tenho um interesse especial por Web Pentesting, reconhecimento, análise de aplicações, exploração de vulnerabilidades e segurança de APIs. Gosto de estudar metodologias, experimentar novas técnicas, desenvolver meus próprios scripts e criar abordagens para investigar sistemas de diferentes perspectivas.

Não me limito a utilizar ferramentas prontas. Tenho uma forte curiosidade em entender o que acontece por trás de cada requisição, cada resposta e cada comportamento inesperado de uma aplicação. Busco constantemente aprimorar minhas habilidades, desenvolver técnicas de análise e expandir meus conhecimentos em segurança ofensiva.

Para mim, hacking vai muito além de encontrar uma falha: é questionar, investigar, experimentar e compreender profundamente a tecnologia.
